On-device AI

Experimental

Filter posts without a cloud API.

Gemini Nano runs in Chrome. Posts, rules, and feedback stay on this device. No API key is needed.

Before you start

The first setup downloads a model. You’ll need compatible desktop hardware and at least 22 GB of free storage. iPhone is not supported.

What it can read

Text and available image descriptions. Image analysis is unavailable. English prompts are supported; other languages may fail.

Model status

Checking availability…

Keep this tab open during setup. Once ready, you can close it and refresh or restart Chrome safely. If Chrome removes the model, filtering pauses until you set it up again. It never switches to cloud AI automatically.
